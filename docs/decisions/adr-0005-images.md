# ADR-0005 — Images and media

Status: Accepted

Context:
Project and portrait images on the reference are hosted on `framerusercontent.com`. The brief forbids permanent hotlinking and using assets whose license is unclear.

Decision:
- Ship original `MediaPlaceholder` components: CSS gradients, geometric composition, and locally authored SVG in `public/`.
- Match aspect ratio and radius, not photographic content.
- Trusted-by marks are generic wordmarks (Inter/Geist, muted), not traced vendor logos.
- Use `next/image` only for local raster files if any are added later. SVG placeholders can be inline or `next/image` with SVG.
- Open Graph image is generated by the App Router (`opengraph-image.tsx`) or a local PNG in `public/`.

Consequences:
- Side-by-side screenshots will differ in photography and brand logos; layout, type, and color remain the comparison criteria.
- No `framerusercontent.com` URLs in production code.
